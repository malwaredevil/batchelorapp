BATCHELOR APP — FULL UI/UX NAVIGATION TEST PLAN
Version 1.0 | Desktop Browser Only | Read-Only (No Data Created or Edited)
Base URL: https://app.batchelor.app
Assumptions: Tester is already logged in. No logout required.
═══════════════════════════════════════════════════════════════════════════════

TOOL RECOMMENDATION: Use Perplexity Comet Browser (not Perplexity Computer).
Comet Browser is purpose-built for navigating websites in a real browser
session. It will click links, read page content, scroll, and take screenshots
exactly as a human tester would. Perplexity Computer controls the full OS
desktop — far more scope than needed for a web UI navigation test.

───────────────────────────────────────────────────────────────────────────────
INSTRUCTIONS FOR THE TESTER
───────────────────────────────────────────────────────────────────────────────
1. Follow every numbered step exactly as written.
2. After each step, record PASS, FAIL, or SKIP and any notes in the scoring
   card at the end of this document.
3. "Page loads successfully" means: the browser navigates to the URL, no
   full-page error screen appears, no spinner runs indefinitely (more than
   10 seconds), and the main content of the page is visible.
4. "Element is visible" means you can see it without scrolling unless the
   step explicitly says "scroll down."
5. Do NOT click any button that says "Add," "Save," "Delete," "Upload,"
   "Remove," "Submit," "Confirm," "Reset," or "Send" — this test is
   read-only navigation only.
6. If a page shows an empty state (e.g., "No items yet"), that is a PASS as
   long as the page itself loaded without an error.
7. If any page shows a blank white screen, a "Something went wrong" error, a
   404, or an infinite spinner, mark it FAIL and note what you see.
8. Score each test case: PASS = 1 point, FAIL = 0 points.
9. SKIP = not applicable (no data to test). Skips do not count against score.
10. Calculate the final score at the end using the formula in the Scoring Card.
